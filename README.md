Sentinel DFIR

Intelligent Digital Forensics & Incident Response Platform

Sentinel DFIR is a cybersecurity graduation project focused on simplifying digital evidence investigation and incident analysis, with Egyptian small and medium-sized enterprises (SMEs) as the intended target users.

The platform aims to provide a structured workflow for validating digital evidence, normalizing data from multiple sources, and supporting incident investigations through traceable, evidence-based analysis.

Project Goals

* Validate evidence integrity and structure before analysis.
* Normalize evidence from different Windows security sources into a consistent event format.
* Preserve traceability between investigation findings and their original evidence records.
* Support a more structured digital forensics and incident response workflow.

Current Development

The project is being developed incrementally, starting with evidence contracts and validation, followed by evidence normalization and subsequent investigation capabilities.
